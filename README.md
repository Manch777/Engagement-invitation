# Engagement Invitation

A responsive digital engagement invitation website built with HTML, CSS, and JavaScript.

The project was created as a real-world digital invitation and includes an interactive opening screen, event information, a countdown timer, venue details, and navigation to the event location.

## Live Demo

View the live website:

https://manch777.github.io/Engagement-invitation/

## Features

- Responsive design for mobile and desktop devices
- Interactive invitation opening
- Event date and time information
- Countdown timer
- Calendar with the event date
- Venue information
- Map and location navigation
- Armenian-language interface
- Custom animations and visual styling

## Technologies

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## Project Structure

- `index.html` — page structure and content
- `style.css` — responsive layout, styling, and animations
- `script.js` — interactive functionality and countdown logic

## Purpose

This project demonstrates the development of a lightweight, responsive event website using vanilla web technologies without external frameworks.
